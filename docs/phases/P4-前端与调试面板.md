## 2. 后端配套改动（源码级）

### 2.1 静态托管 + 路由隔离（server.py，修 C15）

```python
from fastapi.staticfiles import StaticFiles
from fastapi.responses import FileResponse

STATIC_DIR = Path(__file__).parent / "static"
# /api/* 全部在 StaticFiles 挂载之前注册；API 永不 3xx（评测不跟随跳转）
@app.get("/{full_path:path}", include_in_schema=False)
def spa_fallback(full_path: str):
    if full_path.startswith("api/"):
        return JSONResponse(status_code=404, content={"error": "no such api"})
    target = (STATIC_DIR / full_path).resolve()
    if target.is_file() and STATIC_DIR in target.parents:
        return FileResponse(target)
    return FileResponse(STATIC_DIR / "index.html")   # SPA history fallback
```

## 3. 组件源码级设计要点

**TrendChart.vue**：watch filters → `GET /api/metrics/daily` → ECharts option；无数据日 aov=null 不画点；加分项"图表联动"：ChatPanel 回答含日期窗口时 emit → 图表 `markArea` 高亮该区间。

**DataQuality.vue**：`/api/data_quality` 返回 `{cleaning_report: {raw_rows, removed:{六项}, kept_rows,...}, data_period, kb_warnings}` → 横向柱状图 + 顶部一行"保留 18290 + 剔除 338 = 原始 18628"守恒校验展示。

**ChatPanel.vue**：
- session_id：`crypto.randomUUID()` 存 sessionStorage（刷新不断会话，新标签不串线——呼应 D14 修复）。
- 发送 → POST /api/chat → 渲染 answer；`answer_type` 五色徽章（data/doc/hybrid/refusal/clarify）。
- citations → CitationChip 列表，点击展开 quote；data_evidence → EvidenceDrawer。
- trace_id → 点击打开 TraceOverlay。
- 流式（加分项）：EventSource /api/chat/stream；`reasoning` 阶段显示"思考中…"动画，**reasoning_content 绝不渲染进回答区**（契约 §7.3 流式顺序：先 reasoning 后 content）。

**TraceOverlay.vue**（第四关核心，现场调试 30 分的直接支撑）：
```
顶部：trace_id / 问题 / answer_type / 总耗时
时间线（按 at_ms 排序渲染 steps）：
  plan（意图/槽位/改写后查询）
  retrieve（每个 chunk：doc_id/chunk_id/分数/padded/dropped_instructions；filtered 列表及原因）
  tool_calls（tool/params/result 折叠 JSON）
  llm_calls（完整 prompt 与 raw 输出，大体积按路径懒加载）
  number_lock / response
底部：errors（type/message/traceback）
```
