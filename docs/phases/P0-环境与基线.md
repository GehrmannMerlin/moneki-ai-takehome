## 2. Makefile 源码级设计

```makefile
# 平台探测：Windows 的 venv 可执行文件在 Scripts/，POSIX 在 bin/
ifeq ($(OS),Windows_NT)
PY := .venv/Scripts/python.exe
else
PY := .venv/bin/python
endif

.PHONY: setup rebuild run test eval baseline
setup:    ; python -m venv .venv && $(PY) -m pip install -r requirements.txt
rebuild:  ; $(PY) -m kbqa.rebuild
run:      ; $(PY) -m uvicorn kbqa.server:app --host 127.0.0.1 --port 8000
test:     ; $(PY) -m pytest tests -q
eval:     ; cd .. && python eval/run_eval.py --base-url http://localhost:8000 --questions eval/public_questions.jsonl
baseline: ; $(PY) scripts/baseline_report.py
```

README 直接命令表（无 make 环境等价物，Windows PowerShell 与 bash 各一份）：
```
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # POSIX: .venv/bin/python
.venv/Scripts/python -m kbqa.rebuild
.venv/Scripts/python -m uvicorn kbqa.server:app --port 8000
```

> 沙箱注意（已实测）：`cleaning.py:141` 的 `target.unlink()` 在 WorkBuddy 沙箱会被 safe-delete 拦截，本地外部终端无此问题；测试统一用 `VAR_DIR=<临时目录>` 环境变量绕开（`config.py:68` 已支持 `VAR_DIR` 环境变量，直接利用，不改代码）。
